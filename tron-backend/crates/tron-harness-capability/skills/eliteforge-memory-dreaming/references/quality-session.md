# 会话摘要质量

合并已接受的分段结果，形成会话级分析摘要，不直接创建最终记忆点。

## 规则

- 来源为已接受的分段输出；需要重读原文时只通过 CLI 提供的材料页读取。
- 合并重复信号时保留范围、主题、用途和全部有效证据；采用最新且明确有效的修正。
- 保留被丢弃内容及污染原因，供轻量提取阶段判断为什么不记。
- 区分长期信号与临时执行结果，不虚构最终记忆状态。

## 内容重点

字段名以当前 schema 为准：`summary` 表达最终会话结果；`keyPoints` 包括最终决策、稳定事实、风险和复用流程；`candidateSignals` 合并长期信号；`discardedIntermediateFindings` 说明修正、失败、临时或污染内容；`evidenceIndex` 将稳定结论映射到分段标识、来源角色、信任边界和引用。

摘要可以省略无用尝试，但不能删除影响结论的失败、修正或证据边界。

## 示例与复核

合格：两个片段重复同一仓库规范，合并为一个信号并保留两处证据。后一个片段修正前一个配置，保留最终值及替代关系。

不合格：把仓库规则扩大到所有未来项目；把助手怀疑当稳定偏好；删除全部拒绝理由；只引用会话摘要而无法定位原始证据。

提交前确认压缩后仍能判断结论来源，临时任务成功或失败没有被当作长期事实。
