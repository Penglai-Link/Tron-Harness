# Chat Polling Stop

## Goal

Stop polling completed chat sessions while preserving recovery for active runs.

## Design

The page polls only while a local stream, backend active run, queued message, or pending user-input request exists. A recent user message may trigger the initial recovery query, but it cannot keep the polling timer active after that query confirms no active run.

## Scope

Update the chat management page's polling predicate and its focused state tests. Do not change API contracts or backend behavior.

## Verification

Test that an idle session with a recent user message does not continue polling after active-run status resolves to empty. Run the focused frontend unit test and the frontend build check.
