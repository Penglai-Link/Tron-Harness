# 默认 Tab 的右侧面板归属

## 目标

当没有有效的普通 tab 时，右侧面板仍可打开、显示并缓存。隐藏的 `DEFAULT_TAB_ID` 是唯一保底 tab，负责承载这段期间的右侧面板状态。

## 行为

- 初始化时保留默认 tab，但不在 tab bar 中显示。
- 创建普通 tab 后激活普通 tab。
- 关闭或清空所有普通 tab 后，保留并激活默认 tab。
- 默认 tab 不可关闭；普通 tab 的关闭行为保持不变。
- 右侧面板打开状态和尺寸按 tab 保存。无普通 tab 时读写默认 tab。
- 右侧面板内容通过默认 tab 的缓存记录挂载；切换到普通 tab 后继续保留默认 tab 的缓存，切回时恢复。

## 实现边界

- 在 tab store 中集中维护默认 tab，避免清空操作产生空 tab 集合。
- 面板容器以 store 的有效活动 tab 为准，不依赖可见 tab bar 是否有项目。
- 为 store 和右侧面板增加回归测试，覆盖清空、关闭最后一个普通 tab、面板状态更新和缓存恢复。

## 验证

- 使用 `make fe-check` 执行前端构建与类型检查。
- 使用前端单元测试验证默认 tab 生命周期及面板缓存行为。
