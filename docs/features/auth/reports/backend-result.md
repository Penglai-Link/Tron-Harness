# Backend Report: auth

## Summary

Backend auth is complete. Axum now exposes internal login, provider discovery, session inspection, refresh, logout, and GitHub OAuth App authorize or callback routes, all backed by JWT session material, SQLite refresh-session persistence, and existing user-management identity records. Protected APIs now accept `Authorization: Bearer <access-jwt>` with cookie fallback, and successful auth injects request-scoped operator context for downstream write handlers. The deterministic dev provider is disabled by default and retained only for controlled test scenarios.
