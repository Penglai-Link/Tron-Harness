# Backend Report: auth

## Summary

Backend auth now includes LDAP credential login alongside internal and GitHub flows. The backend exposes `POST /api/v1/auth/login/ldap`, surfaces LDAP in provider discovery, reads LDAP settings from YAML or the requested environment variables, and reuses the shared external-auth auto-provision plus provider-subject-link path so a first successful LDAP login creates a local user when none exists. On 2026-06-09 the repo-level backend compilation gap was also cleared by restoring the missing MCP runtime HTTP and stdio submodules, so `rtk make be-check` is green again.
