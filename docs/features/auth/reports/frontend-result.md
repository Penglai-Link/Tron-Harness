# Frontend Report: auth

## Summary

Frontend auth is complete. The app now keeps the access JWT in runtime memory, rebuilds that state from the backend refresh-cookie contract on page load or OAuth callback, blocks anonymous access to protected routes, keeps redirect intent, exposes internal and GitHub OAuth login entry points, and provides an explicit logout path that returns the operator to `/login`.
