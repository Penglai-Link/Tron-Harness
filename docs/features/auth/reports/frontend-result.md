# Frontend Report: auth

## Summary

Frontend auth now exposes three real login paths on the same surface: internal credentials, GitHub OAuth2, and LDAP credentials rendered below GitHub. The app keeps the access JWT in runtime memory, rebuilds that state from the backend refresh-cookie contract on page load or OAuth callback, silently renews access before idle expiry, retries the first expired protected request after a successful refresh, blocks anonymous access to protected routes, blocks non-admin no-space users on an authorization-request page, lets platform admins continue, keeps redirect intent, and provides an explicit logout path that returns the operator to `/login`. The login inputs now carry explicit labels so auth browser smoke can verify GitHub and LDAP flows reliably.
