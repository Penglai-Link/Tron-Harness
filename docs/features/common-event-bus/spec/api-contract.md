# API Contract: Common Event Bus

## API Overview

This feature defines an internal Rust API, not an HTTP API. The contract exists so producers can publish one normalized event shape while sinks remain pluggable and independently bounded.

## Public Types

| type | role | contract notes |
| --- | --- | --- |
| `EventBusHandle` | cloneable publisher | injected into services and runtime components; publish path must be non-blocking |
| `BusEventDraft` | producer input | mutable builder input validated into a normalized `BusEvent` |
| `BusEvent` | immutable admitted event | shared across sinks as `Arc<BusEvent>` |
| `BusRouteClass` | routing taxonomy | `Audit`, `Observe`, `Agui` |
| `BusPriority` | admission priority | `Critical`, `Standard`, `Debug` |
| `BusOutcome` | business outcome hint | `Success`, `Failure`, `Rejected`, `Started`, `Progress`, `Completed` |
| `BusSubjectRef` | business subject | `subject_type` plus optional stable `subject_code` |
| `BusActorRef` | actor context | system actor or authenticated user context |
| `BusRequestRef` | request and trace context | request id, trace id, route, session key, and optional stream key |
| `BusEventAttr` | bounded metadata entry | compact key/value facts for filters and sinks |
| `PublishOutcome` | admission result | accepted, rejected, or dropped with explicit reason |
| `EventSink` | sink contract | bounded sink queue plus sink-local worker logic |
| `BusRuntimeStats` | operational visibility | queue and drop counters plus AGUI replay gauges |

## Suggested Rust Shape

```rust
pub trait EventPublisher: Send + Sync {
    fn publish(&self, event: BusEventDraft) -> PublishOutcome;
}

pub trait EventSink: Send + Sync {
    fn name(&self) -> &'static str;
    fn accepts(&self, event: &BusEvent) -> bool;
    fn try_enqueue(&self, event: Arc<BusEvent>) -> SinkEnqueueOutcome;
}
```

The shared runtime owns dispatcher loops and sink workers. Producers only see the publisher side.

## Event Envelope

### Required Header

| field | type | guidance |
| --- | --- | --- |
| `event_id` | `SnowflakeId` | generated by shared provider or deterministic test fixture |
| `event_name` | `&'static str` or bounded string | use module-scoped constants such as `user.created`, `workspace.archived`, `task.status_changed`, `agui.run.progress` |
| `route_class` | enum | `Audit`, `Observe`, `Agui` |
| `priority` | enum | `Critical`, `Standard`, `Debug` |
| `producer` | `&'static str` or bounded string | module or runtime source such as `user_service`, `workspace_service`, `agent_runtime` |
| `occurred_at_ms` | `i64` | UTC epoch millis |
| `outcome` | enum | success, failure, progress, or completion signal |

### Optional Compact Context

| field | cap | notes |
| --- | --- | --- |
| `subject_type` | 32 bytes | compile-time constant when possible |
| `subject_code` | 64 bytes | stable business code such as `USR-001` or `WS-123` |
| `actor_user_code` | 64 bytes | omit for pure system events |
| `session_code` | 64 bytes | useful for auth and AGUI |
| `request_id` | 64 bytes | generated or propagated from middleware |
| `trace_id` | 64 bytes | optional external correlation id |
| `stream_key` | 64 bytes | required for AGUI stream fan-out, optional elsewhere |
| `summary` | 160 bytes | short human-readable reason or change summary |

### Bounded Extension Fields

- `attrs`: maximum 8 entries
- `attr_key`: maximum 32 bytes
- `attr_value`: maximum 96 bytes
- `payload`: optional, maximum 1024 bytes

`payload` is for compact structured summaries only. Full entity snapshots, large tool output, full prompts, request bodies, and secrets are not valid payloads.

## Admission Contract

- `publish` validates caps before queue admission.
- Oversize events return a rejection outcome and increment counters.
- Admission chooses the `critical` or `standard` lane from `priority`.
- `publish` never awaits sink work and never serializes sink-specific JSON before queue admission.

## Sink Contract

### Audit Sink

- Accepts a selected subset of `Audit` events.
- Batches writes on a sink-local worker and connection.
- Does not leak persistence schema concerns back into producers.

### Observability Sink

- Accepts `Observe` plus selected queue-pressure and failure events.
- Can emit counters, logs, or traces.
- Should aggregate repeated low-cardinality events rather than store raw copies forever.

### AGUI Sink

- Accepts `Agui` and selected `Audit` or `Observe` events when they have a relevant `stream_key`.
- Maintains replay only for active streams.
- Applies per-stream and global memory budgets before keeping replay.

## Producer Guidance

- Publish after the mutation has committed and after repository locks are released.
- Prefer event constants and compact summaries over dynamic string assembly.
- Use `Audit` only for business-significant and security-significant events.
- Use `Agui` only when the event is useful to an active runtime viewer or step timeline.
- Use `Observe` for operational signals, error mapping, queue pressure, retry state, or integration timing.

## Error And Outcome Contract

`PublishOutcome` must distinguish at least:

- `Accepted`
- `RejectedInvalid`
- `RejectedOversize`
- `DroppedIngressFull`
- `DroppedSinkFull`

Business code must not assume accepted means durably stored. Only a future audit persistence sink can claim durable storage.
