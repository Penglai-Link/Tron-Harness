# Agent 持续终端工具

新增 `terminal` 工具领域，按现有领域发现机制加载。复用手动终端使用的 portable-pty 引擎，但不调用面向用户的 `ShellIntegration`，不注入平台 AI 命令。用户明确启动的 shell 仍可能读取自己的配置；工具说明建议使用干净 shell 参数。

| 工具 | 用途 |
| --- | --- |
| `terminal_start` | 启动程序，立即返回终端标识和状态 |
| `terminal_read` | 从输出游标开始分页读取，返回下一游标和退出状态 |
| `terminal_write` | 发送输入，可发送换行或 Control-C |
| `terminal_stop` | 停止终端进程，保留已缓存输出 |
| `terminal_list` | 仅列出当前会话的终端状态，不回放日志 |

终端仅用于需要长期挂起或交互的服务、程序，由 Agent 显式调用 `terminal_start`。实时成功结果打开对应终端标签；历史工具卡片只提供手动打开入口。普通非交互命令仍由 `bash_exec` 通过 stdout/stderr 管道执行；最多等待 10 秒，超时后转入后端后台任务并返回 `taskId` 和输出游标。Agent 使用 `bash_task_read` 查询状态、分段读取结果及最终退出码，必要时调用 `bash_task_stop` 结束任务。不要用 `nohup` 或 shell 后台符号启动服务，使用 `terminal_start` 保持服务和终端会话关联。

两个执行工具都接受 `{"command":"npm run dev"}` 这种完整命令行；省略 `args` 时，命令由用户默认 Shell 以非交互 `-c` 执行。提供 `args` 时按原样作为 argv 直接执行，包括显式空数组。`terminal_start` 通过 `{"interactive":true}` 打开用户默认交互 Shell，此时不能传 `command` 或 `args`；单独启动裸 `bash`、`zsh` 等命令会被拒绝，避免意外留下空终端。Windows 的完整命令字符串沿用 `cmd /C`。

会话由后端持有，不依赖前端连接，同一会话的后续 Agent run 可以继续操作。按工作区、用户、对话隔离；没有对话标识时只在当前 run 内共享。启动目录使用现有应用/worktree 解析和目录访问检查，已有进程不随应用选择变化而迁移。返回的 cwd 是启动目录；程序自身执行 cd 不会更新这个字段。

## 输出与短期记忆

单次读取最多取 32 KiB 原始输出，内存保留最近 256 KiB。游标落后于缓存时明确返回 `truncated`，早期未读内容不保留；如需完整长期日志，应由命令重定向到文件。输出包含终端控制字符，stdout/stderr 合并；文本按 UTF-8 容错解码。

工具返回值继续走 `ToolObservation` 和现有 `record_tool_result`：正常对话记入 transcript，超过原阈值后复用大工具结果转存。后台未读取的日志不自动写入 transcript。进程退出与输出流关闭分别标识，Agent 应读到输出流关闭并消费完输出。

最多保留 64 个会话，每个对话最多 8 个；达到容量时回收已退出会话。后端正常释放时清理进程；后端重启不恢复终端。macOS/Linux 停止时同时处理终端进程组和前台作业组；主动脱离终端的守护进程不保证清理。

## 页面交互

终端工具使用可读卡片展示动作、命令、启动目录和进程状态；“工具操作已完成”不代表进程已退出。实时成功的 `terminal_start` 结果只打开一次标签，历史卡片重放不自动开终端；用户仍可从卡片手动打开。调用 ID 用于启动幂等，相同调用重试返回原终端；同命令的独立调用仍会新建进程。显式“停止”通过后端共享实例结束进程，状态同步到工具和页面。

Agent 终端标签、选中项、日志游标按会话保存。切换会话只展示该会话的标签；关闭标签、收起面板、卸载视图和页面断线不停止进程。标签与选中项使用 sessionStorage，可在同一浏览器标签刷新后恢复；日志和游标在页面内缓存，刷新后重新从后端最近 256 KiB 缓冲区读取。后端重启不恢复进程，旧标签显示不可用；终端标识跨重启不复用。Agent 输出使用与手动终端一致的 ANSI 调色板及应用明暗主题背景/前景色。

底部只保留一套面板和标签栏。`+` 创建手动交互终端标签；Agent 启动的进程也显示在这里，输出只读，输入由 Agent 工具负责。两类标签共用展开、收起入口，但手动终端仍由页面 socket 持有、Agent 进程由后端持有；切换或隐藏 Agent 标签不停止服务。新增文案使用标准 en-US/zh-CN 国际化。后端列表、读取、停止接口都按工作区、当前用户和对话校验终端归属，页面读取不消耗 Agent 的游标，也不写入模型上下文。
