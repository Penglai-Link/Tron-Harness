# 前端技术栈

前端按领域组织，应用启动、路由、领域模块、共享组件、状态和国际化分别维护。领域功能位于 `src/domain`，基础 UI 位于 `src/components/ui`，跨领域能力位于 `src/shared`。

本文依据 [package.json](../package.json)、工作区包和源码核对。表中的版本是依赖声明范围；实际安装版本以 `package-lock.json` 为准。桌面壳的依赖由 `electron` 目录单独管理。

## React Bits 与动效

React Bits 通过本地组件适配接入，未以同名 npm 包声明。实现位于 `src/shared/motion`，包括 `AnimatedContent`、`FadeContent` 和 `ShinyText`，用于页面入场、内容淡入及加载文字等动效。来源和改编说明见 [NOTICE.md](../src/shared/motion/NOTICE.md)，许可保存在 `public/licenses/react-bits.txt`。

| 技术 | 声明版本或来源 | 当前用途 |
| --- | --- | --- |
| React Bits | 项目内改编源码 | 内容入场、淡入和文字渐变扫光。 |
| `gsap` | `^3.13.0` | `BitsContent.tsx` 的入场补间动画与清理。 |
| `@personai/agent-ui-motion-react` | `1.0.0-preview.21` | 共享动效契约、Provider 和动效偏好。 |
| `three`、`postprocessing` | `^0.184.0`、`^6.39.1` | 本地 `PixelBlast` 组件的 WebGL 渲染和后处理；当前未发现页面引用，不能视为已启用的登录背景。 |

`TronMotionProvider` 把本地入场、淡入效果接入 Agent UI，并统一应用系统偏好、减少动效和关闭动效设置；Portal 中的基础组件同步使用该策略。`ShinyText` 使用 CSS 播放，并遵循同一动效策略。

## Agent UI 与聊天适配

Agent UI 依赖从公共 npm 安装，版本统一固定为 `1.0.0-preview.21`。Tron 的聊天适配包通过 npm workspaces 管理。

| 包 | 当前职责 |
| --- | --- |
| `@personai/agent-ui-chat-core` | 公共会话、消息、事件与适配器契约。 |
| `@personai/agent-ui-chat-react` | React 聊天界面、消息呈现和交互组件。 |
| `@personai/agent-ui-chat-theme` | 公共聊天主题样式。 |
| `@personai/agent-ui-terminal` | 公共终端界面；Tron 终端组件通过 `ref` 暴露 `TerminalHandle`，转发 `clear()`、`getSelection()`、`focus()`。 |
| `@tron/chat-core` | Tron 宿主聊天契约与产品字段。 |
| `@tron/chat-internal-adapter` | 内部 API、SSE、AG-UI 事件及附件请求。 |
| `@tron/chat-agent-ui-adapter` | 将 Tron 宿主契约转换为公共 Agent UI 契约，保留产品上下文。 |
| `@tron/chat-openapi-adapter` | 工作区内的 Open API 适配包，提供开放接口认证与传输；未列为当前前端应用的直接依赖。 |

A2UI 的聊天呈现随公共聊天组件接入；本应用的依赖清单没有独立的 A2UI 包。聊天、SSE 和附件请求须使用当前文档语言的 `Accept-Language`。
