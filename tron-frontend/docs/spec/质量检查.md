# 前端质量检查

按实际变更范围执行检查，并记录命令、结果和未验证部分。本文列出应检查的行为，不表示每项已有自动化覆盖，也不表示仅构建成功即可确认页面可用。

## 命令入口

在仓库根目录通过 Makefile 执行：

| 命令 | 实际检查范围 |
| --- | --- |
| `make fe-check` | 构建前端工作区包，执行 `tsc -b` 和 Vite 生产构建 |

前端自动化测试及其运行配置已移除。`fe-check` 负责类型检查与生产构建，不包含独立 ESLint 检查；页面行为通过浏览器核对。仅在用户明确要求时编写测试代码。

纯文档修改核对路径、引用与描述即可，不必为文档重复执行完整应用构建。涉及源码时运行构建并核对相关行为；涉及共享包或后端契约时补充对应检查。

## 按变更选择检查

| 变更 | 重点 |
| --- | --- |
| 路由、应用壳、身份与导航 | 页面保护、重定向、活动菜单、持久化导航、标签页保活与身份切换 |
| API、查询和状态 | 请求上下文、业务响应、加载/空/错、取消、竞态、重试及重复提交 |
| 表单、表格与基础组件 | 标签关联、键盘、焦点、禁用/无效状态、选中行、固定列和滚动 |
| 主题与资源 | 浅色/深色/导入皮肤、变量继承、Portal 字体、资源清理及预览还原 |
| 动效 | `system/reduced/off`、系统减少动效、页面可见性、保活标签页及卸载清理 |
| 聊天与 A2UI | 流式输出、回放、停止、结构化提问和提交状态；检查相应适配器和共享组件 |

按上表在浏览器中检查受影响的功能，记录操作、实际结果和未验证部分。

## 国际化与布局

- 核对 `en-US`、`zh-CN` 的新增和修改文案，包含图标按钮名称、字段错误、弹窗和状态提示。
- 检查翻译键与资源对应关系。当前严格 TypeScript 检查不能保证发现所有错误翻译键。
- 浏览器中检查应用壳及受影响页面的语言切换、刷新后的偏好恢复、`document.lang` 与请求语言头一致性。
- 检查两种语言下侧栏、按钮、标签页、表头、卡片、弹窗和表单控件的长文本、换行及溢出。
- 检查窄屏、长标识符和横向滚动；必要时确认弹窗焦点和可访问名称。

按实际操作记录语言与页面范围，不能将未检查的页面标记为已验证。

## 结果说明

交付时写明实际运行的检查及数据源。Mock 请求或浏览器拦截通过，只证明该测试条件下的前端行为；真实后端、远端服务和已安装客户端的验证需要各自证据。无法运行的检查应说明具体原因，不能标记通过。

文档变更还需检查中文文件名、相对链接、源码路径及仓库内旧引用，并执行 `git diff --check`。
